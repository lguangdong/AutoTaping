### 发现的问题（非 S0 验收项）
1. `App._consecutiveUiExceptionCount` 从不重置 → 实现是「累计 3 次退出」，文档 01 第 6 节要求「连续 3 次」。
2. `appsettings.json` 的 `Hardware.UseVirtual = false`，S2 接入 Virtual 实现后需要按无硬件场景切 true。
3. 07 文档 9.1 要求 Resources 下 Colors/Fonts/Styles/Icons 四个字典；当前 Fonts 常量合并进 Styles.xaml、无 Icons.xaml（S0 清单只要求 Colors+Styles，S3 做导航图标时补）。
4. 日志文件为 UTF-8 无 BOM，PowerShell 5.1 直接 `Get-Content` 读中文会乱码，需 `-Encoding UTF8`。

## 修复：界面异常「连续 3 次」语义（问题 1）

- 改动文件：`src/AutoTaping.App/App.xaml.cs`
- 新增常量 `UiExceptionContinuousWindowMs = 30_000` 与字段 `_lastUiExceptionTick`（`Environment.TickCount64` 单调时钟）。
- 计数逻辑：两次界面异常间隔 ≤ 30s → `count+1`；否则重置为 1。这样「连续」有了判定依据，不再是一天累计 3 次偶发异常就退进程。
- 选型理由：单调时钟不受系统改时间影响；无需额外定时器；初值 0 保证首次异常从 1 开始。
- 已验证 `dotnet build` 0 warning / 0 error。
- 后续若客户要求更严格/宽松，只需调窗口常量，不要改计数逻辑。
