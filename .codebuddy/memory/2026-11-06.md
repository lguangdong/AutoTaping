### 关键决策（后续阶段沿用）
1. 时间列统一 `TEXT`，格式 `yyyy-MM-dd HH:mm:ss`；写入用 `SqliteTime.ToDb`，读取用 `SqliteTime.FromDb`，不依赖驱动隐式格式。
2. 每次操作新建 SQLite 连接（WAL + `Default Timeout=5` 忙等），所有写操作包事务。
3. 仓储行映射用私有嵌套 Row 类 + 显式时间转换，公开实体不带数据库痕迹。
4. `Recipe.Update` 由 SQL 侧 `Version = Version + 1`，实体上的 Version 不回写（调用方需 GetById 刷新）。
5. 取新建主键用同事务内 `SELECT last_insert_rowid();`（不依赖 SQLite 3.35+ 的 RETURNING）。
6. 断电检测：表中无 `LastShutdownClean` 键视为首次启动（不算异常），否则 `!= "1"` 即判非正常退出；检测后立即置 `"0"`。
7. JSON 序列化关闭中文转义（UnsafeRelaxedJsonEscaping），导出文件工程师可直接阅读/手改。
8. `appsettings.json` 的 `Storage:DatabasePath` 相对程序目录解析为绝对路径。
