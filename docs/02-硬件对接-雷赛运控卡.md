# 02 - 硬件对接：雷赛运动控制卡

> ⚠️ **型号未确认**
> 本文档以 **DMC2410 / DMC2410C 系列**为参考（最常见的 4 轴 PCI 卡）。
> 若你的型号是 DMC5800 / SMC6490 / DMC-E（EtherCAT）等，**函数名与参数可能不同**，
> 但**只允许修改 `LeadshineMotionCard.cs` 和 `Native/LeadshineApi.cs` 两个文件**，不许动接口。

---

## 1. 抽象接口（定义在 Core/Abstractions/IMotionCard.cs）

```csharp
namespace AutoTaping.Core.Abstractions;

/// <summary>轴标识</summary>
public enum AxisId { X = 0, Y = 1, Z = 2, R = 3 }

/// <summary>运动控制卡抽象。所有方法必须线程安全。</summary>
public interface IMotionCard : IDisposable
{
    /// <summary>初始化板卡。返回 false 表示失败（调用方降级为 Virtual）。</summary>
    bool Initialize();

    /// <summary>板卡是否已连接</summary>
    bool IsConnected { get; }

    // ---------- 状态 ----------
    /// <summary>读取轴当前位置（已换算为 mm 或 deg）</summary>
    double GetPosition(AxisId axis);

    /// <summary>轴是否到位（true = 已停止且到位）</summary>
    bool IsInPosition(AxisId axis);

    /// <summary>读取停止原因。正常=0，限位=1，急停=2，软限位=3，驱动报警=4</summary>
    int GetStopReason(AxisId axis);

    // ---------- 回零 ----------
    /// <summary>回零（不阻塞，需轮询 IsInPosition）</summary>
    void Home(AxisId axis);

    /// <summary>回零是否完成</summary>
    bool IsHomeCompleted(AxisId axis);

    // ---------- 运动 ----------
    /// <summary>绝对定位（不阻塞）。速度为 mm/s。</summary>
    void MoveAbsolute(AxisId axis, double position, double speed);

    /// <summary>相对移动（不阻塞）</summary>
    void MoveRelative(AxisId axis, double distance, double speed);

    /// <summary>点动：持续运动，调用 Stop 才停。dir = 1 正 / -1 负</summary>
    void JogStart(AxisId axis, int direction, double speed);

    /// <summary>停止。emergency=false 减速停，true 急停</summary>
    void Stop(AxisId axis, bool emergency);

    /// <summary>全轴急停</summary>
    void EmergencyStopAll();

    /// <summary>清轴状态（急停解除后必须调用才能再动）</summary>
    void ResetAxis(AxisId axis);

    /// <summary>软限位设置</summary>
    void SetSoftLimit(AxisId axis, bool enable, double min, double max);

    /// <summary>按当前速度曲线移动到一点并等待到位（阻塞，带超时）。
    /// 供流程引擎使用；timeoutMs 超时返回 false。</summary>
    Task<bool> MoveAndWaitAsync(AxisId axis, double position, double speed, int timeoutMs, CancellationToken ct);

    // ---------- 事件 ----------
    /// <summary>轴异常（限位、驱动报警），由采集线程触发</summary>
    event EventHandler<AxisFaultEventArgs>? AxisFault;
}

public sealed class AxisFaultEventArgs : EventArgs
{
    public AxisId Axis { get; init; }
    public int Reason { get; init; }
    public string Message { get; init; } = "";
}
```

## 3. 雷赛 DLL 声明（Native/LeadshineApi.cs）

> 函数签名以 `LTDMC.dll` 官方头文件 / 手册为准。以下为 DMC2410 系列的常见形式。
> 返回类型 `ushort`，**0 表示成功**，非 0 为错误码。

```csharp
using System.Runtime.InteropServices;

namespace AutoTaping.Hardware.Motion.Native;

internal static class LeadshineApi
{
    private const string Dll = "LTDMC.dll";

    // 板卡
    [DllImport(Dll)] internal static extern ushort dmc_board_init();
    [DllImport(Dll)] internal static extern ushort dmc_board_close();
    [DllImport(Dll)] internal static extern ushort dmc_board_reset();

    // 轴参数
    [DllImport(Dll)] internal static extern ushort dmc_set_pulse_outmode(ushort card, ushort axis, ushort outmode);
    [DllImport(Dll)] internal static extern ushort dmc_set_equiv(ushort card, ushort axis, double equiv);
    [DllImport(Dll)] internal static extern ushort dmc_set_profile_unit(
        ushort card, ushort axis, double minVel, double maxVel, double tAcc, double tDec);
    [DllImport(Dll)] internal static extern ushort dmc_set_dec_stop_time(ushort card, ushort axis, double stopTime);

    // 回零
    [DllImport(Dll)] internal static extern ushort dmc_set_home_profile_unit(
        ushort card, ushort axis, double homeVel, double homeAcc, ushort homeMode);
    [DllImport(Dll)] internal static extern ushort dmc_home_move(ushort card, ushort axis);
    [DllImport(Dll)] internal static extern ushort dmc_get_home_result(ushort card, ushort axis, out ushort stopFlag);

    // 限位信号逻辑
    [DllImport(Dll)] internal static extern ushort dmc_set_elogic(ushort card, ushort axis, ushort elogic);
    [DllImport(Dll)] internal static extern ushort dmc_set_einlogic(ushort card, ushort axis, ushort einlogic);

    // 运动
    [DllImport(Dll)] internal static extern ushort dmc_pmove_unit(
        ushort card, ushort axis, double dist, ushort posiMode);   // posiMode: 0=相对 1=绝对
    [DllImport(Dll)] internal static extern ushort dmc_vmove(ushort card, ushort axis, ushort dir);
    [DllImport(Dll)] internal static extern ushort dmc_stop(ushort card, ushort axis, ushort stopMode); // 0=减速 1=急停
    [DllImport(Dll)] internal static extern ushort dmc_emg_stop(ushort card);

    // 状态
    [DllImport(Dll)] internal static extern ushort dmc_check_done(ushort card, ushort axis); // 0=运动中 1=到位
    [DllImport(Dll)] internal static extern ushort dmc_get_position_unit(ushort card, ushort axis, out double pos);
    [DllImport(Dll)] internal static extern ushort dmc_get_stop_reason(ushort card, ushort axis, out ushort reason);

    // 软限位
    [DllImport(Dll)] internal static extern ushort dmc_set_softlimit_unit(
        ushort card, ushort axis, ushort enable, ushort sourceSel, double positive, double negative);

    // IO
    [DllImport(Dll)] internal static extern ushort dmc_read_inbit(ushort card, ushort bitNo);
    [DllImport(Dll)] internal static extern ushort dmc_read_outbit(ushort card, ushort bitNo);
    [DllImport(Dll)] internal static extern ushort dmc_write_outbit(ushort card, ushort bitNo, ushort onOff);
    [DllImport(Dll)] internal static extern ushort dmc_read_inport(ushort card, ushort portNo);
    [DllImport(Dll)] internal static extern ushort dmc_read_outport(ushort card, ushort portNo);
    [DllImport(Dll)] internal static extern ushort dmc_write_outport(ushort card, ushort portNo, ushort value);
    [DllImport(Dll)] internal static extern ushort dmc_set_doelogic(ushort card, ushort bitNo, ushort logic);
    [DllImport(Dll)] internal static extern ushort dmc_set_inbit_filter(ushort card, ushort bitNo, ushort filterMs);
}
```

### 3.1 型号适配指引

| 型号 | 可能的差异 |
|---|---|
| DMC2410 / DMC2410C | 4 轴，上述 API 基本可用 |
| DMC5800 | 可能为 `dmc_*_unit` 系列，需核对手册 |
| SMC6490 | 部分函数前缀不同 |
| DMC-E（EtherCAT） | 需先扫描从站，函数差异较大 |

**统一策略**：把"函数名差异"全部收敛到 `LeadshineApi.cs`，上层只认 `LeadshineMotionCard` 的实现。

## 4. LeadshineMotionCard 实现要点

```csharp
public sealed class LeadshineMotionCard : IMotionCard
{
    private readonly ushort _cardNo;
    private readonly Dictionary<AxisId, AxisConfig> _config;
    private readonly SemaphoreSlim _lock = new(1, 1);   // ★ DLL 非线程安全，必须串行化
    private readonly ILogger<LeadshineMotionCard> _log;

    public bool Initialize()
    {
        var ret = LeadshineApi.dmc_board_init();
        if (ret != 0) { _log.LogError("板卡初始化失败，错误码 {Code}", ret); return false; }

        foreach (var (axis, cfg) in _config)
        {
            var ax = (ushort)axis;
            Check(LeadshineApi.dmc_set_equiv(_cardNo, ax, cfg.PulsesPerUnit), "set_equiv", axis);
            Check(LeadshineApi.dmc_set_profile_unit(_cardNo, ax, cfg.MinSpeed, cfg.MaxSpeed, cfg.AccTime, cfg.DecTime), "set_profile", axis);
            Check(LeadshineApi.dmc_set_elogic(_cardNo, ax, cfg.PosLimitLogic), "set_elogic", axis);
            Check(LeadshineApi.dmc_set_einlogic(_cardNo, ax, cfg.NegLimitLogic), "set_einlogic", axis);
            Check(LeadshineApi.dmc_set_softlimit_unit(_cardNo, ax, 1, 0, cfg.MaxLimit, cfg.MinLimit), "set_softlimit", axis);
        }
        return true;
    }

    public void MoveAbsolute(AxisId axis, double position, double speed)
    {
        _lock.Wait();
        try
        {
            // 速度参数是"单位/秒"，雷赛在 set_profile_unit 里设最大速度，
            // 若需动态调速，重新 set_profile_unit 后再发运动指令
            SetSpeedInternal(axis, speed);
            Check(LeadshineApi.dmc_pmove_unit(_cardNo, (ushort)axis, position, 1), "pmove_abs", axis);
        }
        finally { _lock.Release(); }
    }

    public async Task<bool> MoveAndWaitAsync(AxisId axis, double position, double speed,
                                             int timeoutMs, CancellationToken ct)
    {
        MoveAbsolute(axis, position, speed);
        var sw = Stopwatch.StartNew();
        while (sw.ElapsedMilliseconds < timeoutMs)
        {
            ct.ThrowIfCancellationRequested();
            if (IsInPosition(axis)) return true;

            var reason = GetStopReason(axis);
            if (reason != 0)
            {
                _log.LogError("轴 {Axis} 异常停止，原因 {Reason}", axis, reason);
                return false;
            }
            await Task.Delay(10, ct);   // 10ms 轮询足够，别用 1ms 空转
        }
        _log.LogWarning("轴 {Axis} 运动超时 {Timeout}ms", axis, timeoutMs);
        Stop(axis, emergency: true);
        return false;
    }

    private void Check(ushort ret, string op, AxisId axis)
    {
        if (ret != 0) throw new HardwareException($"运控卡 {op} 失败，轴={axis}，错误码={ret}");
    }
}
```

### 4.1 单位换算

| 轴 | 单位 | 换算方式 |
|---|---|---|
| X / Y / Z | mm | `dmc_set_equiv(card, axis, PulsesPerMm)` 后，所有 `*_unit` 函数直接用 mm |
| R | 度 | `PulsesPerDeg` 作为 equiv |

**禁止**在业务代码里做脉冲换算，全部由 `equiv` 处理。

### 4.2 停止原因映射

| `dmc_get_stop_reason` 返回值 | 含义 | 处理 |
|---|---|---|
| 0 | 正常停止 | 无 |
| 1 | 正/负限位触发 | 报警 `AL101`，需反向点动退出 |
| 2 | 急停 | 报警 `AL100`，需 `ResetAxis` |
| 3 | 软限位 | 报警 `AL102`，参数或路径错误 |
| 4 | 驱动报警 | 报警 `AL103`，需检查伺服 |

### 4.3 安全要求（强制）

1. **回零前必须确认安全门关闭**（`X05 = 1`），否则拒绝执行
2. **Z 轴运动前必须确认不处于贴附位**，或强制先抬到安全高度
3. **急停后所有运动指令必须被拒绝**，直到 `ResetAxis` 成功
4. **任何 `Stop` 之后，500ms 内禁止下发新运动**（防止 DLL 状态未复位）

## 5. VirtualMotionCard（模拟实现，必须实现）

**用途**：无硬件开发、演示、单元测试。

### 5.1 行为要求

| 行为 | 模拟规则 |
|---|---|
| 运动耗时 | `耗时(ms) = |距离| / speed * 1000`，最小 20ms |
| 位置推进 | 每 20ms 更新一次位置，线性插值 |
| 到位判断 | 到达目标后 `IsInPosition = true`，`StopReason = 0` |
| 软限位 | 超出范围时拒绝运动并触发 `AxisFault(reason=3)` |
| 回零 | 模拟 1.5s 后位置归 0，`IsHomeCompleted = true` |
| 急停 | 立即停止，所有后续运动被拒绝直到 `ResetAxis` |
| 编码器 | 与位置一致（无误差） |

### 5.2 实现提示

```csharp
public sealed class VirtualMotionCard : IMotionCard
{
    private readonly double[] _pos = new double[4];
    private readonly double[] _target = new double[4];
    private readonly double[] _speed = new double[4];
    private readonly bool[] _moving = new bool[4];
    private readonly System.Threading.Timer _timer;

    // 每 20ms 推进所有运动中的轴
    private void Tick(object? _)
    {
        for (int i = 0; i < 4; i++)
        {
            if (!_moving[i]) continue;
            double step = _speed[i] * 0.02;   // 20ms
            if (Math.Abs(_target[i] - _pos[i]) <= step)
            {
                _pos[i] = _target[i];
                _moving[i] = false;
            }
            else _pos[i] += Math.Sign(_target[i] - _pos[i]) * step;
        }
    }
}
```

## 6. 验收标准

| # | 标准 | 验证方法 |
|---|---|---|
| 1 | `Initialize()` 在无卡时返回 false 且不抛异常 | 拔卡启动程序 |
| 2 | 无卡时自动降级到 Virtual，UI 可用 | 同上，能进手动页并点动 |
| 3 | 4 轴都能点动、能停 | 手动页操作 |
| 4 | 回零完成标志正确 | 手动页显示"已回零" |
| 5 | 超软限位被拒绝并报警 | 手动输入超范围目标 |
| 6 | 急停后运动被拒绝 | 点急停 → 再点运动 → 提示"请先复位" |
| 7 | 多线程并发调用不崩 | 同时点动 X 和 Y |
| 8 | Virtual 模式模拟 500 件不崩 | 自动流程连跑 |

## 7. 本文件的约束

1. 所有 P/Invoke 声明只能出现在 `Native/LeadshineApi.cs`
2. 所有对 DLL 的调用必须经过 `_lock`（`SemaphoreSlim`）
3. 不得在业务层做脉冲换算
4. 必须实现 Virtual 版本，且行为符合上表
5. 硬件异常必须包装为 `HardwareException`，不得裸露错误码到 UI
