# 04 - 视觉与标定

> 本项目为 **2D 黑白** 视觉，相机装在贴胶头侧面（**Eye-in-Hand**），随头移动；工件停在线体工位上不动。
> 目标：把"像素坐标"变成"头坐标（龙门 mm）"，并算出每件来料的位置/角度偏差，贴附时由头跟随补偿。

**两个必须记住的结论**：

1. **相机与吸嘴不同轴**（相差 40~60mm），所以"拍照位"不是工位中心，而是**头的站位**：
   ```
   PhotoPos = StationCenter − CameraOffset
   ```
   即头要往前/后让一段，相机光轴才落在工件中心。
2. 相机偏置 `CameraOffset` 必须由**手眼标定**实测，不能靠机械图纸：
   头吸一个标定针，分别在相机视野内几个点触碰标定板，拟合出「像素 → 头坐标」的固定偏置。
   标定一次长期有效，但换相机/换吸嘴/撞机后必须重标。

---

## 1. 四个坐标系

| 坐标系 | 符号 | 单位 | 说明 |
|---|---|---|---|
| **像素坐标系** | (u, v) | pixel | 图像左上角为原点，向右 u 增，向下 v 增 |
| **相机坐标系** | (u', v') | pixel | 以图像中心为原点（可选，用于减少数值量级） |
| **平台坐标系** | (X, Y) | mm | 运控卡坐标，回零后为 (0, 0) |
| **工件坐标系** | (x, y, θ) | mm, ° | 以 MARK 为基准的局部坐标系 |

**变换链**：
```
像素 (u,v) --[仿射矩阵 M]--> 平台 (X,Y) --[叠加纠偏]--> 目标位置
```

## 2. 九点标定

### 2.1 原理

平台移动到 9 个已知的机械位置，每个位置拍照并识别 MARK 的像素坐标。
用最小二乘拟合二维仿射变换：

```
[ X ]   [ a  b  c ] [ u ]
[ Y ] = [ d  e  f ] [ v ]
                    [ 1 ]
```

6 个未知数，每对点提供 2 个方程 → **至少 3 个点**，9 点用于提高精度与鲁棒性。

### 2.2 标定流程（UI 上点"开始标定"后执行）

```
1. 安全检查：Z 轴抬到安全高度
2. 平台移动到九宫格第 1 点 (X1, Y1)
3. 等待到位 + 稳定延时 200ms（消除机械振动）
4. 软触发拍照
5. 识别 MARK 像素坐标 (u1, v1)，识别失败 → 中止并报错
6. 重复 2-5，共 9 点
7. 拟合仿射矩阵 M
8. 计算残差 RMS
9. RMS < 阈值 → 保存标定结果；否则提示重标
```

九宫格点位（以标定区域中心为基准，边长 L）：

```
(X0-L, Y0+L)   (X0, Y0+L)   (X0+L, Y0+L)
(X0-L, Y0)     (X0, Y0)     (X0+L, Y0)
(X0-L, Y0-L)   (X0, Y0-L)   (X0+L, Y0-L)
```

**推荐 L = 50 mm**（覆盖工作区域，又不超出相机视野）。

### 2.3 拟合代码（OpenCvSharp）

```csharp
namespace AutoTaping.Vision;

public sealed class CalibrationResult
{
    public double[] AffineMatrix { get; init; } = new double[6]; // a b c d e f
    public double RmsError { get; init; }
    public DateTime CreatedAt { get; init; }
    public int PointCount { get; init; }
    public bool IsValid => RmsError >= 0 && RmsError < 0.1 && PointCount >= 3;

    /// <summary>像素 → 平台</summary>
    public (double X, double Y) PixelToPlatform(double u, double v)
    {
        var m = AffineMatrix;
        return (m[0] * u + m[1] * v + m[2],
                m[3] * u + m[4] * v + m[5]);
    }
}

public sealed class CalibrationService
{
    /// <param name="pixelPoints">9 个像素坐标</param>
    /// <param name="platformPoints">9 个对应的平台 mm 坐标</param>
    public CalibrationResult Calibrate(Point2f[] pixelPoints, Point2f[] platformPoints)
    {
        if (pixelPoints.Length < 3 || pixelPoints.Length != platformPoints.Length)
            throw new ArgumentException("标定点数量不合法");

        using var src = Mat.FromArray(pixelPoints);      // Nx2, CV_32F
        using var dst = Mat.FromArray(platformPoints);

        using var affine = Cv2.EstimateAffine2D(src, dst);   // 返回 2x3 Mat
        if (affine.Empty()) throw new InvalidOperationException("仿射变换求解失败");

        var m = new double[6];
        // affine 是 2x3: [a b c; d e f]
        m[0] = affine.At<double>(0, 0);
        m[1] = affine.At<double>(0, 1);
        m[2] = affine.At<double>(0, 2);
        m[3] = affine.At<double>(1, 0);
        m[4] = affine.At<double>(1, 1);
        m[5] = affine.At<double>(1, 2);

        // 计算残差
        double sumSq = 0;
        for (int i = 0; i < pixelPoints.Length; i++)
        {
            double px = m[0] * pixelPoints[i].X + m[1] * pixelPoints[i].Y + m[2];
            double py = m[3] * pixelPoints[i].X + m[4] * pixelPoints[i].Y + m[5];
            double dx = px - platformPoints[i].X;
            double dy = py - platformPoints[i].Y;
            sumSq += dx * dx + dy * dy;
        }
        double rms = Math.Sqrt(sumSq / pixelPoints.Length);

        return new CalibrationResult
        {
            AffineMatrix = m,
            RmsError = rms,
            CreatedAt = DateTime.Now,
            PointCount = pixelPoints.Length
        };
    }
}
```

### 2.4 精度判据

| RMS | 评价 | 处理 |
|---|---|---|
| < 0.02 mm | 优秀 | 可用 |
| 0.02 – 0.05 mm | 良好 | 可用 |
| 0.05 – 0.10 mm | 可接受 | 可用，但建议重标 |
| > 0.10 mm | 不合格 | **必须重标**，检查机械/镜头/特征识别 |

**常见残差大的原因**（写进 UI 提示）：
1. MARK 识别不稳定（光照变化 / 特征太弱 / 模板不好）
2. 平台定位误差（皮带间隙、丝杆背隙）
3. 拍照时未等机械稳定（延时不够）
4. 标定区域太小（九宫格步长 < 20mm，误差被放大）
5. 镜头畸变（用远心镜头可消除）

## 3. MARK 识别

### 3.1 方案选择

| 方案 | 适用 | 优点 | 缺点 |
|---|---|---|---|
| **模板匹配**（推荐） | 实心圆/异形 MARK | 鲁棒、易调，实心圆对旋转免疫 | 对直径（尺度）敏感 |
| **找圆心**（HoughCircles） | 圆形 MARK | 亚像素精度高、旋转尺度都无关 | 参数敏感 |
| **轮廓 + 重心** | 高对比 MARK | 快 | 对噪声敏感 |
| **角点**（GoodFeaturesToTrack） | 十字交叉 | 精度高 | 需要 ROI 限制 |

**默认实现：模板匹配 + 亚像素细化。**

MARK 设计：**两个不同直径的实心圆**（默认半径 15px / 9px）。

- **身份由直径区分**，不再按左右划分搜索区域——实测半径差 2~3px 时交叉得分仍有 0.70~0.81，会互相误判；
  **半径差 ≥4px（约 1mm @4px/mm，物理上直径差 ≥2mm）才可靠**。
- **两个模板共用一块搜索区域**（`searchRoi`），只负责省算力与防误检：
  实测 1280×1024 全图两次匹配约 32ms，合并单 ROI 约 4ms，两块小 ROI 约 1.3ms。
- 命中后做**两点间距校验**（实测间距偏离标称值超容差即判失败），拦住"某个模板命中了画面里的干扰圆"。
- **搜索区域属于配方、由标称位置推导**（早期 `mark1Roi/mark2Roi` 左右分治方案已彻底删除，旧 JSON 键在启动时自动清理）。
  模板制作只写模板路径与基准像素坐标，**改写搜索区域会导致搜索区退化成模板尺寸（result 1×1 → 坐标恒为区域中心）**。

### 3.2 模板匹配实现

```csharp
public sealed class TemplateMatcher
{
    private Mat? _template;

    public void LoadTemplate(string path)
    {
        _template?.Dispose();
        _template = Cv2.ImRead(path, ImreadModes.Grayscale);
        if (_template.Empty()) throw new FileNotFoundException($"模板不存在: {path}");
    }

    /// <summary>在 ROI 内搜索模板，返回亚像素中心点</summary>
    public Point2f? Match(Mat image, Rect roi, double threshold = 0.7)
    {
        if (_template is null || _template.Empty()) return null;
        if (!IsRoiValid(image, roi)) return null;

        using var search = new Mat(image, roi);
        using var result = new Mat(
            search.Rows - _template.Rows + 1,
            search.Cols - _template.Cols + 1,
            MatType.CV_32FC1);

        Cv2.MatchTemplate(search, _template, result, TemplateMatchModes.CCoeffNormed);
        Cv2.MinMaxLoc(result, out _, out double maxVal, out _, out Point maxLoc);

        if (maxVal < threshold) return null;

        // 亚像素细化：对峰值做 3x3 抛物线拟合
        var sub = RefineSubPixel(result, maxLoc);
        return new Point2f(
            roi.X + sub.X + _template.Width / 2f,
            roi.Y + sub.Y + _template.Height / 2f);
    }

    /// <summary>抛物线插值求亚像素峰值（提升约 0.1px 精度）</summary>
    private static Point2f RefineSubPixel(Mat result, Point p)
    {
        float dx = 0, dy = 0;
        if (p.X > 0 && p.X < result.Cols - 1)
        {
            float l = result.At<float>(p.Y, p.X - 1);
            float c = result.At<float>(p.Y, p.X);
            float r = result.At<float>(p.Y, p.X + 1);
            float denom = 2 * (2 * c - l - r);
            if (Math.Abs(denom) > 1e-6) dx = (l - r) / denom;
        }
        if (p.Y > 0 && p.Y < result.Rows - 1)
        {
            float t = result.At<float>(p.Y - 1, p.X);
            float c = result.At<float>(p.Y, p.X);
            float b = result.At<float>(p.Y + 1, p.X);
            float denom = 2 * (2 * c - t - b);
            if (Math.Abs(denom) > 1e-6) dy = (t - b) / denom;
        }
        return new Point2f(p.X + dx, p.Y + dy);
    }

    private static bool IsRoiValid(Mat img, Rect roi) =>
        roi.Width > 0 && roi.Height > 0 &&
        roi.Right <= img.Width && roi.Bottom <= img.Height;
}
```

### 3.3 双 MARK 纠偏计算

```csharp
public sealed class CorrectionResult
{
    public double DeltaX { get; init; }   // mm
    public double DeltaY { get; init; }
    public double DeltaTheta { get; init; } // 度
    public bool IsValid { get; init; }
    public string? Message { get; init; }
}

public sealed class CorrectionService
{
    /// <param name="mark1Pixel">当前拍照得到的 MARK1 像素坐标</param>
    /// <param name="mark2Pixel">当前拍照得到的 MARK2 像素坐标</param>
    /// <param name="template1Pixel">标定时记录的 MARK1 像素坐标</param>
    /// <param name="template2Pixel">标定时记录的 MARK2 像素坐标</param>
    public CorrectionResult Compute(
        Point2f mark1Pixel, Point2f mark2Pixel,
        Point2f template1Pixel, Point2f template2Pixel,
        CalibrationResult calib)
    {
        // 1. 角度偏差
        double curAngle = Math.Atan2(mark2Pixel.Y - mark1Pixel.Y, mark2Pixel.X - mark1Pixel.X);
        double refAngle = Math.Atan2(template2Pixel.Y - template1Pixel.Y, template2Pixel.X - template1Pixel.X);
        double dTheta = (curAngle - refAngle) * 180.0 / Math.PI;

        // 2. 以两点中点为参考，计算像素位移
        var curMid = new Point2f((mark1Pixel.X + mark2Pixel.X) / 2, (mark1Pixel.Y + mark2Pixel.Y) / 2);
        var refMid = new Point2f((template1Pixel.X + template2Pixel.X) / 2, (template1Pixel.Y + template2Pixel.Y) / 2);

        // 3. 像素位移 → 平台位移（用标定矩阵的线性部分，不含平移）
        var (curX, curY) = calib.PixelToPlatform(curMid.X, curMid.Y);
        var (refX, refY) = calib.PixelToPlatform(refMid.X, refMid.Y);

        double dX = curX - refX;
        double dY = curY - refY;

        // 4. 合理性检查（防止识别错误导致设备乱跑）
        if (Math.Abs(dX) > 5 || Math.Abs(dY) > 5 || Math.Abs(dTheta) > 10)
        {
            return new CorrectionResult
            {
                IsValid = false,
                Message = $"纠偏量异常：ΔX={dX:F2} ΔY={dY:F2} Δθ={dTheta:F2}，请检查识别结果"
            };
        }

        return new CorrectionResult
        {
            DeltaX = dX, DeltaY = dY, DeltaTheta = dTheta, IsValid = true
        };
    }
}
```

> **安全阈值必须有**：识别错误（比如把反光当成 MARK）会算出离谱的纠偏量，直接把工件贴飞甚至撞机。上面 5mm / 10° 的限制是硬性保护。

## 4. R 轴旋转中心补偿

### 4.1 问题

R 轴旋转时，吸嘴不是绕自己转，而是绕**旋转中心** C 转。若 C 与吸嘴中心 P 不重合，
旋转 θ 后吸嘴会偏离目标位置：

```
P' = C + R(θ) · (P - C)

其中 R(θ) = [cosθ  -sinθ]
            [sinθ   cosθ]
```

展开：
```
Δx = (Px - Cx)(cosθ - 1) - (Py - Cy)·sinθ
Δy = (Px - Cx)·sinθ      + (Py - Cy)(cosθ - 1)
```

### 4.2 实现

```csharp
public static class RotationCompensation
{
    /// <summary>计算旋转 θ 后吸嘴的额外偏移（需要加到目标位置上的补偿量）</summary>
    public static (double CompX, double CompY) Compute(
        double nozzleX, double nozzleY,
        double centerX, double centerY,
        double thetaDeg)
    {
        double t = thetaDeg * Math.PI / 180.0;
        double cos = Math.Cos(t), sin = Math.Sin(t);

        double dx = nozzleX - centerX;
        double dy = nozzleY - centerY;

        // 旋转后的位置
        double newX = centerX + dx * cos - dy * sin;
        double newY = centerY + dx * sin + dy * cos;

        // 补偿量 = 目标 - 实际
        return (nozzleX - newX, nozzleY - newY);
    }
}
```

### 4.3 旋转中心怎么来的

| 方法 | 做法 | 精度 |
|---|---|---|
| **两点法**（推荐） | 吸嘴移到 MARK 上方，R 转 0° 记录 P1，转 180° 记录 P2，中心 = (P1+P2)/2 | ±0.05mm |
| **三点法** | 转 0/120/240°，三点求外接圆圆心 | ±0.02mm |
| **厂家给定** | 机械设计给出理论值 | 依赖装配精度，通常要实测 |

**UI 要求**：提供"旋转中心标定"向导，引导用户做两点法。

## 5. 完整纠偏调用链（流程引擎里的顺序）

```csharp
// 1. 移动到拍照位
await _motion.MoveAndWaitAsync(AxisId.X, photoPosX, 100, 5000, ct);
await _motion.MoveAndWaitAsync(AxisId.Y, photoPosY, 100, 5000, ct);

// 2. 拍照
var frame = await _camera.TriggerAndGrabAsync(3000, ct);
if (!frame.Success) throw new FlowException("拍照失败");

// 3. 识别两个 MARK
using var mat = ImageConverter.ToMat(frame.Mono8Data!, frame.Width, frame.Height);
var m1 = _matcher1.Match(mat, _recipe.SearchRoi);   // 两个 MARK 共用一块搜索区域
var m2 = _matcher2.Match(mat, _recipe.SearchRoi);
if (m1 is null || m2 is null) throw new FlowException("MARK 识别失败");

// 4. 算纠偏
var corr = _correction.Compute(m1.Value, m2.Value,
                               _recipe.TemplateMark1, _recipe.TemplateMark2, _calib);
if (!corr.IsValid) throw new FlowException(corr.Message!);

// 5. 算目标位置（配方基准点 + 纠偏）
double targetX = _recipe.TapeBaseX + corr.DeltaX;
double targetY = _recipe.TapeBaseY + corr.DeltaY;
double targetR = _recipe.TapeBaseR + corr.DeltaTheta;

// 6. R 轴旋转中心补偿
var (compX, compY) = RotationCompensation.Compute(
    targetX, targetY, _recipe.RotationCenterX, _recipe.RotationCenterY, targetR);
targetX += compX;
targetY += compY;

// 7. 移动
await _motion.MoveAndWaitAsync(AxisId.X, targetX, _recipe.MoveSpeed, 5000, ct);
await _motion.MoveAndWaitAsync(AxisId.Y, targetY, _recipe.MoveSpeed, 5000, ct);
await _motion.MoveAndWaitAsync(AxisId.R, targetR, _recipe.RotateSpeed, 5000, ct);
```

## 7. 验收标准

| # | 标准 | 验证方法 |
|---|---|---|
| 1 | 用合成图（Virtual 模式）能完成九点标定 | 无硬件跑通 |
| 2 | 标定 RMS < 0.1mm | 看 UI 显示 |
| 3 | 注入 ±3px 偏移，纠偏能算出对应 mm 并补偿 | Virtual 注入偏移 |
| 4 | 纠偏量超阈值时拒绝执行并报警 | 把模板改错，看是否拦截 |
| 5 | 旋转中心标定后，转 90° 贴附位置误差 < 0.1mm | Virtual 验证 |
| 6 | 模板匹配单帧耗时 < 50ms（1280×1024） | 打点计时 |
| 7 | 标定结果重启后仍可用 | 重启验证 |

## 8. 本文件的约束

1. 视觉算法只依赖 OpenCvSharp，不依赖任何硬件
2. 所有纠偏结果必须做**合理性检查**，超阈值一律拒绝
3. 标定结果必须落库 + 存原图
4. 搜索区域必须来自配方、由标称 MARK 位置推导；不得硬编码，也**不得由模板制作写入**
5. 图像处理不得在 UI 线程执行
