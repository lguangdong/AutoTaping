# 00 - 项目总览

## 1. 设备工艺描述

**自动贴胶机**：把定长胶带（双面胶/泡棉胶）精确贴附到工件（PCB/壳体/电芯）指定位置的自动化设备。

### 1.1 物理构成

```
                    ┌──────────────┐
                    │  相机（固定）  │  ← Eye-to-Hand，安装在上方
                    └──────┬───────┘
                           │ 俯拍
   ┌───────────────────────▼────────────────────────┐
   │                                                │
   │   [上料位]      [贴附位]        [下料位]         │
   │      │            │               │            │
   │      └──── X/Y 平台移动 ───────────┘            │
   │                                                │
   └────────────────────────────────────────────────┘
                    ▲
              ┌─────┴─────┐
              │  贴胶头    │ Z 轴升降 + R 轴旋转 + 真空吸嘴
              └───────────┘
```

### 1.2 轴定义（4 轴）

| 轴 | 名称 | 行程（示例） | 用途 |
|---|---|---|---|
| X | 横移轴 | 0 ~ 400 mm | 平台左右定位 |
| Y | 纵移轴 | 0 ~ 400 mm | 平台前后定位 |
| Z | 升降轴 | 0 ~ 100 mm | 贴胶头上下 |
| R | 旋转轴 | -180° ~ +180° | 贴胶头角度纠偏 |

> ⚠️ 行程、速度、加速度为**示例值**，实际以机械设计为准，全部写入 `appsettings.json`。

### 1.3 IO 定义（示例，实际以电气图为准）

| 类型 | 点位 | 说明 |
|---|---|---|
| DI | X00 | 上料位有料 |
| DI | X01 | 贴附位有料 |
| DI | X02 | 下料位有料 |
| DI | X03 | 真空压力开关（吸住） |
| DI | X04 | 胶带余量检测 |
| DI | X05 | 安全门（闭合=1） |
| DI | X06 | 急停（常闭，正常=1） |
| DI | X07 | 气压低报警 |
| DO | Y00 | 真空阀 |
| DO | Y01 | 吹气阀（破真空） |
| DO | Y02 | 压合气缸下压 |
| DO | Y03 | 三色灯-绿 |
| DO | Y04 | 三色灯-黄 |
| DO | Y05 | 三色灯-红 |
| DO | Y06 | 蜂鸣器 |

## 2. 自动流程（标准节拍）

```
[待机] 
  → 检测上料位有料（X00=1）
  → X/Y 移动到拍照位
  → 软触发相机拍照
  → 视觉识别 MARK 点，计算偏移 (ΔX, ΔY, Δθ)
  → 坐标变换：像素 → 平台 mm，叠加旋转中心补偿
  → X/Y/R 移动到贴附位（含纠偏量）
  → Z 下降到贴附高度
  → 开真空阀（Y00=1），等待 X03=1（吸住确认，超时报警）
  → Z 上升 / 平台移动到贴附起点
  → 走贴附路径（直线 or 圆弧），同时 Z 按压力曲线下降
  → 保压（延时）
  → 关真空 + 开吹气（Y00=0, Y01=1），延时破真空
  → Z 抬升到安全高度
  → 平台移动到下料位
  → 计数 +1，记录追溯
  → 回到 [待机]
```

**目标节拍**：3.0 ~ 4.0 s/件（示例，实际按机械能力）

## 3. 术语表（UI 与代码必须统一使用）

| 术语 | 英文/代码名 | 含义 |
|---|---|---|
| MARK 点 | `MarkPoint` | 工件上用于定位的特征点（十字/圆） |
| 标定 | `Calibration` | 建立像素坐标与平台坐标的映射关系 |
| 九点标定 | `NinePointCalibration` | 平台走 9 个点，记录像素坐标，拟合仿射矩阵 |
| 偏置 | `Offset` | 贴附位置相对 MARK 的固定偏移量 |
| 纠偏 | `Correction` | 根据拍照结果计算的实时补偿量 (ΔX, ΔY, Δθ) |
| 旋转中心 | `RotationCenter` | R 轴旋转时吸嘴的旋转中心坐标 |
| 保压 | `HoldPressure` / `Dwell` | 贴附后保持压力一段时间 |
| 破真空 | `BlowOff` | 吹气使胶带脱离吸嘴 |
| 吸嘴 | `Nozzle` | 吸附胶带的末端执行器 |
| 节拍 | `CycleTime` | 单件从进入到产出的时间 |
| UPH | `UPH` | Units Per Hour，每小时产量 |
| 良率 | `Yield` | OK 数 / 总数 |
| 软限位 | `SoftLimit` | 软件设定的轴运动边界 |
| 回零 | `Homing` | 寻找机械原点 |
| 点动 | `Jog` | 按住移动、松开停止的手动操作 |
| 配方 | `Recipe` | 一个产品的全部工艺参数集合 |
| 单步 | `SingleStep` | 自动流程走一步就停，用于调试 |

## 4. 功能范围

### ✅ 本期实现

| 模块 | 内容 |
|---|---|
| 主画面 | 工艺流程图、实时状态、关键数值、通讯状态 |
| 手动调试 | 4 轴点动/回零/定位、气缸与真空控制、IO 监控（只读） |
| 参数/配方 | 参数编辑、配方保存/加载/另存/导入/导出、变更审计 |
| 视觉 | 九点标定、MARK 模板制作、实时拍照预览、纠偏计算 |
| 报警 | 三级报警、确认、历史查询、导出 |
| 产量统计 | 当班/累计产量、良率、节拍、停机原因分类 |
| 用户权限 | 操作员/技术员/工程师三级、登录、自动锁屏 |
| 系统 | 通讯状态、操作日志、一键备份、版本信息 |
| 模拟模式 | 无硬件可完整运行（Virtual 实现） |

### ❌ 本期不做（明确排除，避免 AI 自行添加）

| 不做 | 原因 |
|---|---|
| MES 对接 | 用户明确不需要 |
| 远程监控/云平台 | 单机部署 |
| 多工位/多机联线 | 单工位 |
| 实时插补算法 | 由运控卡内部完成 |
| 3D 视觉 | 只有 2D 黑白相机 |
| 自动生成贴附路径（CAD 导入） | 路径由配方手工配置 |
| 报表设计器 | 固定格式导出 CSV |
| 多语言 | 只做简体中文 |
| 数据库服务端（SQL Server/MySQL） | 只用本地 SQLite |

## 5. 用户角色与权限边界

| 角色 | 可做 | 不可做 |
|---|---|---|
| **操作员**（Operator） | 查看主画面、启动/暂停/停止、确认报警、切换配方（只读列表） | 改参数、手动模式、IO 强制、标定、导出数据 |
| **技术员**（Technician） | 以上 + 手动模式、修改工艺参数、配方另存、标定、查看历史报警 | IO 强制输出、删除数据、修改系统设置 |
| **工程师**（Engineer） | 全部 + IO 强制输出、系统设置、数据库维护、删除配方、退出程序 | — |

**权限实现要求**：不只是在界面隐藏，**ViewModel 层必须再校验一次**（防止快捷键绕过）。

## 7. 与硬件的边界（重要）

```
上位机（本项目）              运控卡（雷赛）              伺服/气缸
     │                            │                        │
     │  dmc_pmove_unit(...)  ───► │  内部完成加减速、        │
     │  下发"走到 (x,y) 速度 v"    │  脉冲输出、到位判断      │
     │                            │                        │
     │  ◄─── dmc_check_done() ─── │                        │
```

**上位机不下发单个脉冲，不自己做加减速曲线。**
上位机只做：**决策（去哪、多快、什么时候）+ 时序（先开阀再下降）+ 异常处理**。

## 8. 验收总标准

项目完成的判定（全部满足）：

1. 无硬件环境下，用 `Virtual` 实现可完整演示全部 7 个页面
2. 接入真实相机后，能完成一次九点标定，标定残差 < 0.1 mm
3. 接入真实运控卡后，4 轴可点动、可回零、可定位
4. 自动流程可连续跑 500 件无异常（或 Virtual 模式模拟 500 件）
5. 拔掉相机网线 → 界面报警但不崩溃，插回后自动恢复
6. 参数修改后下一个节拍生效，无需重启
7. 断电重启后，产量/报警/日志数据完整
8. 单元测试覆盖：状态机迁移、坐标变换、参数校验、报警判定
