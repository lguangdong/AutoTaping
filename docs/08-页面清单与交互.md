### 控件清单

| 区域 | 控件 | 内容 | 数据来源 |
|---|---|---|---|
| 工艺流程图 | 4 个工位圆角矩形 | 工位名 + 状态点 + 计数 | `DeviceSnapshot` |
| 工艺流程图 | 连接箭头 | 静态，运行时高亮当前段 | 当前步骤索引 |
| 贴胶头 | 数值文本 ×4 | Z、R、真空、气压 | `DeviceSnapshot` |
| 实时曲线 | `Polyline` ×2 | 真空压力、X 位置（最近 300 点） | 环形缓冲 |
| 状态数据 | 数值卡片 ×4 | 节拍、产量、良率、连续运行 | `StatisticsService` |
| 通讯状态 | 圆点 ×3 + 文本 | PLC/相机/运控卡 | `CommunicationMonitor` |

### 交互规则

| 操作 | 响应 |
|---|---|
| 点击工位 | 弹出该工位详情（当前位置、IO 状态、最近报警） |
| 点击通讯圆点 | 弹出设备详情（IP、最后通讯时间、错误信息） |
| 点击产量卡片 | 跳转 OutputPage |
| **本页无任何修改操作** | 主画面只读，防止误操作 |

### 空状态处理

- 无配方 → 工位区显示"未选择配方，请先到参数页选择"，启动按钮禁用
- 未回零 → 工艺图上方显示黄色横幅"设备未回零，请先执行回零"
- 相机未连接 → 拍照位显示灰色"相机未就绪"

### 交互规则（**这是最容易做错的地方**）

| 操作 | 正确行为 | 错误行为（禁止） |
|---|---|---|
| 点 `►` 按钮 | **按住才动，松开立即停** | 点一下走一段 |
| 轴运动中 | 该轴所有按钮禁用，显示"运动中" | 允许重复下发 |
| 点"回零" | 二次确认 → 执行 → 显示进度 | 直接执行 |
| 输入目标位置 | 超软限位时**输入框红框 + 禁用定位按钮** | 允许输入后运动 |
| 回零未完成 | 定位按钮禁用 | 允许定位 |
| 急停中 | **整个页面所有控制禁用** | 允许点动 |
| 切回自动 | 有轴在运动时拒绝并提示 | 直接切换 |
| IO 强制 | 仅工程师可见；退出页面自动全部清除 | 保留强制状态 |

### 权限控制

| 功能 | 操作员 | 技术员 | 工程师 |
|---|---|---|---|
| 进入本页 | ❌ | ✅ | ✅ |
| 点动 / 回零 / 定位 | — | ✅ | ✅ |
| 气缸/真空控制 | — | ✅ | ✅ |
| IO 强制输出 | — | ❌ | ✅ |

### 安全要求

1. 进入页面必弹确认：「进入手动模式后自动流程将停止，确认进入？」默认「取消」
2. 页面顶部**永久红色横幅**，不可关闭
3. 离开页面时：`ClearAllForcedOutput()` + 停止所有点动 + Z 轴抬到安全高度

```
│ 参数分组树（左侧，220宽） │ 参数编辑区（右侧）                  │

└───────────────────────────────────────────────────────────────┘
```

> **点贴没有「贴附路径」**：分组树只有 工艺 / 位置 / 视觉 / 报警阈值 四组，
> 原「贴附路径」编辑区（路径模式 + 路径点表格 + 圆弧参数）已删除。
> 位置参数里全部是**头坐标**（龙门站位），关键的几项：取料位 `200 / 80`、相机偏置 `0 / 44`
> （相机偏置是手眼标定值，决定拍照位 `photoPos = tapeBase − cameraOffset`）。

### 交互规则

| 操作 | 行为 |
|---|---|
| 修改参数 | 立即校验范围；超范围红框 + 提示范围 + 禁用保存 |
| 保存 | 写库 + 写 `OperationLog`（记录旧值/新值/用户）+ 提示"下一个节拍生效" |
| 切换配方 | 若未保存 → 弹窗"有未保存修改，是否保存？" |
| 另存为 | 弹输入框（名称唯一性校验） |
| 导入 | 选 JSON 文件 → 校验结构 → 预览差异 → 确认导入 |
| 导出 | 保存为 `{配方名}_{yyyyMMdd}.json` |
| 恢复默认 | 二次确认，恢复为代码内置默认值 |

### 参数变更审计（必须）

每次保存，对**每个变更项**写一条日志：

```csharp
_operationLog.Insert(user, "修改参数", $"{recipe.Name}.{paramKey}",
                     oldValue: "400", newValue: "500");
```

```
│ │                                          [全部确认]        │ │

│ ┌─ 历史报警 ─────────────────────────────────────────────────┐ │
│ │ 起 [2026-11-05] 止 [2026-11-05] [查询] [导出CSV]           │ │
│ │ 时间     代码   内容          等级 确认人  恢复时间         │ │

│ └────────────────────────────────────────────────────────────┘ │
└───────────────────────────────────────────────────────────────┘
```

### 交互规则

| 操作 | 行为 |
|---|---|
| 确认单条 | 写 `AckTime` + `AckUser`，从当前列表移除 |
| 全部确认 | **仅工程师可用**，二次确认 |
| 严重报警未确认 | 主状态栏红色徽标闪烁，**禁止启动** |
| 新报警到达 | 表格顶部插入 + 蜂鸣器（可静音 30 分钟） |
| 导出 | UTF-8 BOM CSV |

### 报警去重（重要）

同一 `Code` 在 **5 秒内重复触发**不新增记录，只更新 `EndTime` 与计数。
否则一次机械抖动会刷出几百条，现场无法使用。

## 全局交互约定

| 场景 | 规则 |
|---|---|
| 权限不足 | 控件置灰 + 点击时提示"需要技术员权限" |
| 操作被拒绝 | 弹窗必须说明**原因 + 建议** |
| 长时间操作（标定/备份） | 显示进度 + 可取消 |
| 无操作 5 分钟 | 自动锁定，回登录页（运行中不锁） |
| 快捷键 | **不设快捷键**（触摸屏无键盘，且易误触） |
| 页面切换 | 运行中允许切换到报警/产量页，**禁止切到手动/参数页** |
