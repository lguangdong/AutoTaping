## S0 - 骨架搭建

### 目标
解决方案能编译、能运行、能显示一个空的主窗口。

### 交付物
```
[ ] AutoTaping.sln（6 个项目）
[ ] 项目引用关系正确（Core 不引用 WPF）
[ ] App.xaml.cs：DI 容器 + Serilog + 全局异常处理
[ ] appsettings.json（第 7 节的完整骨架）
[ ] MainWindow.xaml（空壳，能显示标题）
[ ] Resources/Colors.xaml + Styles.xaml（色板与按钮样式）
```

### 验收标准
1. `dotnet build` 成功，0 error
2. 运行后出现窗口，标题「自动贴胶机上位机 v1.0.0」
3. 故意抛异常（临时按钮），弹窗提示且不崩溃
4. `logs/` 下生成日志文件，含启动记录

### 常见坑
- .NET 8 的 WPF 项目需要 `<UseWPF>true</UseWPF>`
- Serilog 要在 DI 之前初始化，否则早期异常无日志

## S2 - 硬件抽象 + Virtual 实现

### 目标
**没有硬件也能跑通全部后续开发。**

### 交付物
```
[ ] IMotionCard / IIoService / ICamera 接口（按 02/03 文档签名）
[ ] VirtualMotionCard（4 轴模拟，含限位/急停/回零）
[ ] VirtualCamera（合成图 + 可注入偏移）
[ ] VirtualIoService（内存点位，可手动置位）
[ ] HardwareException / 错误码映射
[ ] DI 注册：按 appsettings 的 UseVirtual 选择实现
```

### 验收标准
1. `UseVirtual=true` 时，`IMotionCard.Initialize()` 返回 true
2. Virtual 轴：`MoveAbsolute(X, 100, 100)` 后约 1s 到位，位置 = 100
3. Virtual 轴：超软限位被拒绝并触发 `AxisFault`
4. Virtual 轴：急停后运动被拒绝
5. Virtual 相机：连续取 10 帧，每帧 MARK 位置有 ±5px 随机偏移
6. 单元测试：VirtualMotionCard 的位置推进、限位、急停各 1 个用例

### 目标
完整的外框：状态栏 + 导航 + 内容区 + 操作条，8 个页面可切换（内容为空占位）。

### 交付物
```
[ ] MainWindow.xaml（按 08 文档的布局）
[ ] 状态栏：状态灯、配方、产量、良率、报警数、用户、时间（每秒刷新）
[ ] 导航栏：8 个按钮，权限控制显隐/置灰
[ ] 操作条：启动/暂停/停止/复位按钮（暂不接逻辑）
[ ] 8 个 Page 的空壳 + 对应 ViewModel

[ ] 自动锁屏（5 分钟无操作）
```

### 验收标准
1. 8 个导航按钮都能切页，无卡顿
2. 状态栏时间每秒跳动
3. 用 admin 登录后，所有按钮可用；用 operator 登录后，手动页导航置灰
4. 5 分钟无操作自动回登录页
5. 1280×1024 下无滚动条

## S4 - 手动页 + IO 页

### 目标
能真正操作虚拟轴、看到 IO 状态。

### 交付物
```
[ ] ManualPage：4 轴点动/回零/定位 + 速度输入 + 软限位显示
[ ] 气缸/真空/吹气/压合按钮
[ ] IoPage：DI/DO 网格，绿=ON 深灰=OFF，带中文名
[ ] IO 强制输出（工程师权限）
[ ] 进入手动页的确认弹窗 + 红色横幅
[ ] 采集线程（200ms 更新 DeviceSnapshot）
```

### 验收标准
1. 按住 `►` 轴移动，松开立即停
2. 输入超软限位目标，输入框红框 + 定位按钮禁用
3. 急停后，本页所有控制禁用
4. IO 页点位颜色随 Virtual 状态变化
5. 工程师可强制输出，退出页面自动清除
6. 连续操作 10 分钟无异常、无内存增长 > 50MB

## S5 - 视觉模块 + 标定页

### 目标
用 Virtual 合成图完成一次九点标定，并算出纠偏。

### 交付物
```
[ ] ImageConverter（Mono8 ↔ Mat ↔ BitmapSource）
[ ] CalibrationService（EstimateAffine2D + 残差计算）
[ ] TemplateMatcher（模板匹配 + 亚像素 + 阈值）
[ ] CorrectionService（双 MARK 纠偏 + 合理性检查）
[ ] RotationCompensation
[ ] VisionPage：实时预览 + 识别结果 + 九点标定向导
[ ] 模板制作（框选 ROI 保存）
[ ] 标定结果落库 + 存原图
```

### 验收标准
1. Virtual 相机预览流畅（≥10fps）
2. 九点标定能跑完，显示 9 个点 + 残差表
3. 合成图场景 RMS < 0.05mm
4. 注入 ±3px 偏移，纠偏算出对应 mm 值（误差 < 0.05mm）
5. 人为把模板改错，纠偏量超阈值时被拦截并报警
6. 单元测试：已知仿射矩阵反算、90°/180° 旋转补偿

## S6 - 状态机 + 自动流程

### 目标
**虚拟模式下能完整跑通一件**，这是项目的里程碑。

### 交付物
```
[ ] DeviceStateMachine（完整迁移表 + 守卫）
[ ] InterlockChecker（10 条互锁）
[ ] FlowStep 抽象 + 11 个步骤实现（顺序见 05 文档 4.2 节）
    1 CheckPreconditions → 2 WaitCarrier → 3 SettleDelay → 4 CaptureAndCorrect →
    5 MoveToPickPos → 6 PickTape → 7 MoveToTapePos → 8 PressAndHold →
    9 ReleaseTape → 10 ConveyOut → 11 RecordOutput
[ ] AutoFlowEngine（重试、超时、暂停、单步）
[ ] 急停处理流程（按 05 文档顺序）
[ ] AutoPage 主画面（工艺流程图 + 实时数值 + 通讯状态）
[ ] 操作条按钮全部接上逻辑
```

> **产线 + 点贴版说明**：本机是「龙门 XYZR 动、工件由传送带停线定位、胶带点贴」，
> 因此**没有** `TapePath` / `MoveToTapeStart` / `MoveZToTapeHeight` / `MoveZSafe` /
> `MoveToUnloadPos` / `VacuumOn` / `VacuumOffAndBlow` / `HoldPressure` 这些滚贴时代的步骤，
> 也没有对应的验收条目（无路径插补、无 Z 随动、无下料位移动、无独立开真空步骤）。

### 验收标准
1. 未回零时点启动 → 弹窗"4 轴未全部回零"，不发车
2. 安全门打开时点启动 → 提示"安全门未闭合"
3. 回零后可启动，虚拟流程完整走完一件，产量 +1
4. 连跑 100 件不报错（Virtual 模式约 5–6 分钟）
5. 运行中开门 → 立即暂停；关门后点继续 → 从当前步骤恢复
6. 运行中按急停 → 立即停轴 + 关真空 + 红灯亮 + 状态 EStopped
7. 急停释放后点复位 → 引导重新回零
8. 单步模式：点一次启动只走一步
9. 单元测试：状态机 12 个迁移用例、互锁 10 个用例

## S7 - 参数/报警/产量

### 目标
三个业务页面完整可用。

### 交付物
```
[ ] RecipePage：参数分组、范围校验、保存审计、导入导出、另存为
[ ] AlarmPage：当前列表、历史查询、确认、5 秒去重、导出 CSV
[ ] OutputPage：统计卡片、小时柱状图、停机分析、明细表、导出
[ ] AlarmService（触发/去重/恢复/确认）
[ ] OutputService（计数、班次、停机分类）
[ ] 参数热生效（改完下一个节拍生效）
```

### 验收标准
1. 改贴附压力为 0.5 → 红框提示"0.10~0.40"，保存按钮禁用
2. 改参数保存后，`OperationLog` 有一条记录含旧值/新值
3. 模拟触发 AL301 三次（间隔 1s）→ 只产生 1 条记录
4. 确认报警后，从当前列表消失，出现在历史
5. 跑 50 件后，产量页显示正确的总数/良率/平均节拍
6. 导出 CSV 用 Excel 打开中文不乱码
7. 切配方后，下一个节拍使用新参数（无需重启）

## S8 - 真实硬件接入

### 目标
接上雷赛卡和海康相机，跑通真实单件。

### 前置确认（**必须先问用户**）
```
[ ] 雷赛卡型号 → 核对 LTDMC.dll 函数签名
[ ] 轴数量与脉冲当量
[ ] 各轴软限位（机械行程）
[ ] IO 点位实际定义（对照电气图）
[ ] 海康相机型号、分辨率、网口/IP
[ ] 触发方式（软触发 / IO 硬触发）
```

### 交付物
```
[ ] LeadshineMotionCard（P/Invoke 实现）
[ ] HikvisionCamera（MvCameraControl.Net）
[ ] MotionCardIoService（真实 IO）
[ ] 启动自检失败降级逻辑
[ ] 掉线检测与重连
```

### 验收标准
1. 拔掉运控卡 → 启动不崩，降级 Virtual + 报警 AL105
2. 接上卡 → 4 轴能点动、能回零、位置读数正确
3. 相机能枚举、能软触发取图、预览正常
4. 拔网线 → 5s 内 AL201，插回 3s 内恢复
5. 真实标定 RMS < 0.1mm
6. 真实跑通 1 件（先用手动确认每个动作正确，再跑自动）
7. 连续跑 100 件无异常

### ⚠️ 安全要求（真实硬件阶段）

**第一次接真实设备必须遵守**：

1. 先用**手动模式**逐个验证每个动作（尤其是 Z 轴和真空）
2. Z 轴速度先设很低（10mm/s），确认方向正确
3. 软限位必须小于机械行程 5mm
4. 手放在急停上跑第一件
5. **不要**一上来就跑自动

## S9 - 打磨与验收

### 目标
达到「可交付客户」状态。

### 交付物
```
[ ] 每日维护任务（数据归档、日志清理）
[ ] 一键备份（数据库 + 配方 + 模板 + 配置）
[ ] 版本信息页（软件版本、数据库大小、最后标定）
[ ] 用户管理（增删改、改密、禁用）
[ ] 启动自检（磁盘、数据库、硬件）
[ ] 异常兜底（UI 异常不退出）
[ ] README（部署说明、安装步骤、常见问题）
[ ] 压力测试报告
```

### 验收标准
1. **断电测试**：跑 10 件时直接拔电源，重启后数据完整（产出 10 条、无脏数据）
2. **键盘乱按**：所有按键/快捷键乱按 5 分钟不崩
3. **长时间运行**：连续跑 8 小时，内存增长 < 100MB
4. **磁盘满**：模拟磁盘不足，报警 AL501 且不崩溃
5. **数据库只读**：把 db 设为只读，报警 AL502 且继续生产（内存缓冲）
6. **备份恢复**：备份 → 删除数据 → 恢复 → 数据完整
7. **权限穿透**：用 operator 尝试所有越权操作，全部被拒
