# 03 - 硬件对接：海康工业相机（黑白）

> ⚠️ **型号未确认**
> 本文档按 **MVS SDK（MvCameraControl.Net）+ Mono8 像素格式 + 软触发**编写。
> 海康各型号（MV-CA013 / MV-CS050 / MV-CU060…）的 SDK 调用方式一致，
> 差异只在支持的分辨率、帧率、是否支持硬触发。

## 1. 抽象接口（Core/Abstractions/ICamera.cs）

```csharp
namespace AutoTaping.Core.Abstractions;

public sealed class CaptureResult
{
    public bool Success { get; init; }
    public byte[]? Mono8Data { get; init; }     // 灰度原始数据
    public int Width { get; init; }
    public int Height { get; init; }
    public DateTime Timestamp { get; init; }
    public string? ErrorMessage { get; init; }
}

public interface ICamera : IDisposable
{
    bool Initialize();
    bool IsConnected { get; }
    bool IsGrabbing { get; }

    /// <summary>开始采集（连续采集模式，取图靠 TriggerAndGrab）</summary>
    bool StartGrabbing();
    void StopGrabbing();

    /// <summary>软触发一次并取一帧。超时返回 Success=false。</summary>
    Task<CaptureResult> TriggerAndGrabAsync(int timeoutMs, CancellationToken ct);

    /// <summary>仅软触发（用于已配回调模式的场景）</summary>
    void SoftwareTrigger();

    /// <summary>设置曝光（微秒）</summary>
    bool SetExposure(double microseconds);

    /// <summary>设置增益（dB）</summary>
    bool SetGain(double gain);

    /// <summary>相机异常（掉线）</summary>
    event EventHandler<CameraFaultEventArgs>? Fault;
}

public sealed class CameraFaultEventArgs : EventArgs
{
    public string Message { get; init; } = "";
    public int ErrorCode { get; init; }
}
```

## 2. 海康 SDK 关键调用（HikvisionCamera.cs）

### 2.1 依赖

- 安装 **MVS 客户端**（海康机器人官网下载）
- 引用 `MvCameraControl.Net.dll`（位于 `MVS/Development/DotNet/win64/`）
- 运行时需要 `MvCameraControl.dll` 等同目录原生库（MVS 安装时已注册到 PATH）

### 2.2 初始化流程

```csharp
// 1. 枚举设备（GigE + USB）
MyCamera.MV_CC_DEVICE_INFO_LIST deviceList = new();
int ret = MyCamera.MV_CC_EnumDevices(
    MyCamera.MV_GIGE_DEVICE | MyCamera.MV_USB_DEVICE, ref deviceList);

if (ret != MyCamera.MV_OK || deviceList.nDeviceNum == 0)
    throw new HardwareException("未找到工业相机");

// 2. 创建句柄（取第 0 个，或按序列号匹配）
ret = MyCamera.MV_CC_CreateDevice(out IntPtr handle, ref deviceList.pDeviceInfo[0]);

// 3. 打开
ret = MyCamera.MV_CC_OpenDevice(handle, MyCamera.MV_ACCESS_Exclusive, 0);

// 4. GigE 相机必须设置最优包长（否则可能丢帧）
MyCamera.MV_CC_DEVICE_INFO info = /* deviceList.pDeviceInfo[0].struDeviceInfo */;
if (info.nTLayerType == MyCamera.MV_GIGE_DEVICE)
    MyCamera.MV_GIGE_SetOptimalPacketSize(handle);

// 5. 设置触发模式（软触发）
MyCamera.MV_CC_SetEnumValue(handle, "TriggerMode", 1);          // 1 = On
MyCamera.MV_CC_SetEnumValue(handle, "TriggerSource", 7);        // 7 = Software（以枚举名为准）
MyCamera.MV_CC_SetEnumValue(handle, "TriggerActivation", 0);

// 6. 关闭自动曝光/自动增益（工业定位必须固定参数）
MyCamera.MV_CC_SetEnumValue(handle, "ExposureAuto", 0);         // 0 = Off
MyCamera.MV_CC_SetEnumValue(handle, "GainAuto", 0);
MyCamera.MV_CC_SetFloatValue(handle, "ExposureTime", 5000f);    // 5ms
MyCamera.MV_CC_SetFloatValue(handle, "Gain", 0f);

// 7. 开始采集
MyCamera.MV_CC_StartGrabbing(handle);
```

> **枚举值常量**：优先用 SDK 提供的 `MyCamera.MV_CAMERA_...` 常量，不要硬编码数字。
> 若常量名不确定，用字符串节点名（`"TriggerMode"`）+ `MV_CC_SetEnumValueByString`。

### 2.3 取一帧（同步阻塞方式，推荐用于本项目）

```csharp
// 触发
MyCamera.MV_CC_SetCommandValue(handle, "TriggerSoftware");

// 等待并取帧
MyCamera.MV_FRAME_OUT_INFO_EX frameInfo = new();
byte[] buffer = new byte[width * height];   // Mono8 一个像素一字节
IntPtr pData = Marshal.UnsafeAddrOfPinnedArrayElement(buffer, 0);

int ret = MyCamera.MV_CC_GetOneFrameTimeout(
    handle, pData, (uint)buffer.Length, ref frameInfo, (uint)timeoutMs);

if (ret != MyCamera.MV_OK)
    return new CaptureResult { Success = false, ErrorMessage = $"取图失败 0x{ret:X}" };

return new CaptureResult
{
    Success = true,
    Mono8Data = buffer,
    Width = frameInfo.nWidth,
    Height = frameInfo.nHeight,
    Timestamp = DateTime.Now
};
```

**注意**：
- 必须 `fixed` 或 `GCHandle.Alloc` 固定托管数组再取地址（示例用 `UnsafeAddrOfPinnedArrayElement` 需固定）
- 更稳妥的写法：
  ```csharp
  var handle = GCHandle.Alloc(buffer, GCHandleType.Pinned);
  try { ret = MyCamera.MV_CC_GetOneFrameTimeout(h, handle.AddrOfPinnedObject(), ...); }
  finally { handle.Free(); }
  ```
- 缓冲区大小要按**实际帧的 payload 大小**分配（`MV_CC_GetIntValue("PayloadSize")`），不要固定写死

### 2.4 释放（必须按顺序）

```csharp
if (_grabbing) MyCamera.MV_CC_StopGrabbing(_handle);
MyCamera.MV_CC_CloseDevice(_handle);
MyCamera.MV_CC_DestroyDevice(_handle);
```

**掉线检测**：GigE 相机网线拔掉后，`GetOneFrameTimeout` 会超时。捕获超时 → 触发 `Fault` 事件 → 上层报警 → 后台每 3s 尝试重新 `OpenDevice`。

## 3. Mono8 → OpenCV Mat 转换（关键实现）

```csharp
namespace AutoTaping.Vision;

public static class ImageConverter
{
    /// <summary>Mono8 原始数据 → 灰度 Mat（不拷贝，需保证 data 生命周期）</summary>
    public static Mat ToMat(byte[] mono8, int width, int height)
    {
        var mat = new Mat(height, width, MatType.CV_8UC1);
        Marshal.Copy(mono8, 0, mat.Data, width * height);
        return mat;
    }

    /// <summary>Mat → BitmapSource（用于 WPF 显示）</summary>
    public static BitmapSource ToBitmapSource(Mat mat)
    {
        if (mat.Empty()) return BitmapSource.Create(1, 1, 96, 96,
            PixelFormats.Gray8, null, new byte[1], 1);

        // 统一转灰度 8 位
        Mat gray = mat;
        if (mat.Channels() != 1)
        {
            gray = new Mat();
            Cv2.CvtColor(mat, gray, ColorConversionCodes.BGR2GRAY);
        }

        int stride = (int)gray.Step();
        BitmapSource bs = BitmapSource.Create(
            gray.Width, gray.Height, 96, 96,
            PixelFormats.Gray8, null, gray.Data, stride * gray.Height, stride);

        bs.Freeze();   // ★ 必须 Freeze，否则跨线程使用会抛异常
        if (!ReferenceEquals(gray, mat)) gray.Dispose();
        return bs;
    }
}
```

**性能要求**：1280×1024 灰度图，转换 + Freeze < 10ms。

## 4. VirtualCamera（模拟实现，必须实现）

### 4.1 行为要求

| 行为 | 规则 |
|---|---|
| 图片来源 | `Hardware:Camera:SampleImageDirectory` 指定目录（默认 `images/samples`）内的 `*.png/*.bmp/*.jpg`，每次取图**随机取一张**（自动转灰度） |
| 样本图从哪来 | `tools/SampleGen` 生成（随机 ΔX/ΔY/Δθ 的模拟相机画面），构建时复制到输出目录 `images/samples` |
| 无图片时 | 生成带 MARK 的合成图（噪声底 + 大小两个实心圆：r=15 在 (400,500)、r=9 在 (880,500)） |
| 姿态差异 | 不再注入偏移：样本图自带不同姿态，每次拍照的纠偏量天然不同 |
| 平台位置模拟 | 九点标定期间调用 `SetPlatformPosition`，此时**强制走合成图**（像素与平台位置必须确定性对应），标定结束后 `ClearPlatformPosition` 恢复样本图 |
| 触发延迟 | 模拟 80–150ms 取图耗时 |
| 掉线模拟 | 支持"手动断开"按钮，用于演示报警 |

### 4.2 合成图生成（无素材时可用）

```csharp
private byte[] GenerateFrame()
{
    var buffer = new byte[1024 * 1280];
    Array.Fill(buffer, (byte)40);

    // 两个实心圆 MARK（模拟工件特征；圆心落在整数像素，与合成模板同一套像素判定）
    var (m1x, m1y, m2x, m2y) = ComputeMarkPositions();   // 基准 + 平台位移换算
    DrawFilledCircle(buffer, m1x, m1y);
    DrawFilledCircle(buffer, m2x, m2y);

    // 加一点噪声，更接近真实
    ...
    return buffer;
}
```

> 演示价值：样本图模式下每次拍照都是**不同的工件姿态**（ΔX/ΔY/Δθ 来自 SampleGen 的真值），
> 视觉模块算出的纠偏量随之变化，比"每帧都一样"更能证明算法有效。

## 5. 相机参数配置表

| 参数 | 节点名 | 典型值 | 说明 |
|---|---|---|---|
| 曝光 | `ExposureTime` | 3000–8000 μs | 车间 LED 照明下 5ms 左右 |
| 增益 | `Gain` | 0–5 dB | 尽量用 0，增益会放大噪声 |
| 触发模式 | `TriggerMode` | On | 定位应用必须用触发 |
| 触发源 | `TriggerSource` | Software | 上位机控制时机 |
| 像素格式 | `PixelFormat` | Mono8 | 黑白相机最快最省带宽 |
| 帧率使能 | `AcquisitionFrameRateEnable` | false | 触发模式下不需要限帧 |
| 自动曝光 | `ExposureAuto` | Off | **必须关闭**，否则每帧亮度不一致，模板匹配会飘 |

**重要**：自动曝光/自动增益必须关闭。这是新手最常犯的错，也是现场"标定好了但第二天又不准"的主要原因。

## 6. 通信与掉线处理

```
采集线程每 200ms 检查相机状态（通过 ICamera.IsConnected + 最近成功取图时间）
   ↓ 超过 5s 无成功取图
触发 CameraFault 事件
   ↓
AlarmService 报 AL201「相机通讯中断」
   ↓
自动流程：暂停（不是继续乱跑）
   ↓
后台每 3s 尝试重新初始化
   ↓ 成功
清除报警，提示「相机已恢复」，流程保持暂停等待人工确认
```

**不允许**：相机掉线后自动继续跑（可能贴到空位造成撞机）。

## 8. 本文件的约束

1. 所有 SDK 调用只能出现在 `Hardware/Camera/HikvisionCamera.cs`
2. 相机对象**不可多线程并发取图**，必须加锁
3. 取图必须在后台线程，不得在 UI 线程调用
4. `BitmapSource` 必须 `Freeze()` 后才能跨线程
5. 必须实现 Virtual 版本，且能注入偏移模拟
6. 自动曝光必须强制关闭，代码里写死而不是靠配置
