# 03 - 硬件对接：海康工业相机（黑白）

> ✅ **型号已确认：MV-CA060-10GM**（2026-11-18）
> 现场枚举回报的实际机型名是 **`MV-CA060-11GM/JT`**（同系列 600 万像素黑白 GigE 版本，
> 序列号 `00E18241102`，参数与 10GM 一致），代码与文档按「MV-CA060-xxGM 系列」处理。
> 本文档按 **MVS SDK（MvCameraControl.Net）+ Mono8 像素格式 + 软触发**编写。
> 海康各型号（MV-CA013 / MV-CS050 / MV-CU060…）的 SDK 调用方式一致，
> 差异只在支持的分辨率、帧率、是否支持硬触发。
>
> | 项 | MV-CA060 系列实测规格 | 对代码的影响 |
> |---|---|---|
> | 分辨率 | 3072 × 2048（6 MP，Sony IMX178） | Mono8 单帧 = 6 291 456 字节，缓冲区按 PayloadSize 动态分配 |
> | 像素格式 | Mono 8/10/10p/12/12p | 代码强制 Mono8；取图后再校验 `enPixelType`，不是 Mono8 直接报错 |
> | 接口 | GigE（千兆网，C 口镜头） | 必须设最优包长；网卡建议开巨帧 9014 |
> | 帧率 | 最大 17 fps | 触发模式下不限帧，节拍由上位机软触发决定 |
> | 曝光 | 27 μs ~ 2.5 s | 代码按相机自报节点范围夹紧（`MV_CC_GetFloatValue("ExposureTime")`） |
> | 增益 | 0 ~ 20 dB | 同上，默认用 0，优先调曝光 |
> | 触发 | 支持软触发 / 硬触发 | 本项目用软触发（`TriggerSource=Software`） |

## 1. 抽象接口（Core/Abstractions/ICamera.cs）

```csharp
namespace AutoTaping.Core.Abstractions;

public sealed class CaptureResult
{
    public bool Success { get; init; }
    public byte[]? Mono8Data { get; init; }     // 灰度原始数据
    public int Width { get; init; }
    public int Height { get; init; }
    public DateTime Timestamp { get; init; }
    public string? ErrorMessage { get; init; }
}

public interface ICamera : IDisposable
{
    bool Initialize();
    bool IsConnected { get; }
    bool IsGrabbing { get; }

    /// <summary>开始采集（连续采集模式，取图靠 TriggerAndGrab）</summary>
    bool StartGrabbing();
    void StopGrabbing();

    /// <summary>软触发一次并取一帧。超时返回 Success=false。</summary>
    Task<CaptureResult> TriggerAndGrabAsync(int timeoutMs, CancellationToken ct);

    /// <summary>仅软触发（用于已配回调模式的场景）</summary>
    void SoftwareTrigger();

    /// <summary>设置曝光（微秒）</summary>
    bool SetExposure(double microseconds);

    /// <summary>设置增益（dB）</summary>
    bool SetGain(double gain);

    /// <summary>相机异常（掉线）</summary>
    event EventHandler<CameraFaultEventArgs>? Fault;
}

public sealed class CameraFaultEventArgs : EventArgs
{
    public string Message { get; init; } = "";
    public int ErrorCode { get; init; }
}
```

## 2. 海康 SDK 关键调用（HikvisionCamera.cs）

### 2.1 依赖

- 本项目代码按 **MVS 4.x 的 .NET 封装**编写：命名空间 `MvCamCtrl.NET`、设备类 `MyCamera`、
  方法统一带 `_NET` 后缀。
- **托管封装已随仓库内置**：`src/AutoTaping.Hardware/libs/MvCameraControl.Net.dll`
  （取自 MVS SDK Development **4.9.0.3** 的 `DotNet\AnyCpu\netstandard2.0\`，含同名 `.xml` 注释文件）。
  因此编译**不依赖任何环境变量**，克隆仓库即可得到 `HAS_MVS` 生效的真实实现。
- 原生库（`MvCameraControl.dll`、`MvCameraControlWrapper.dll`、`ThirdParty\` 等，约 72 MB）
  **不随仓库携带**，由 MVS 安装程序写入机器 PATH：
  `C:\Program Files (x86)\Common Files\MVS\Runtime\Win64_x64`。
  换机器部署时必须在该机装 MVS（或把上面这个目录加到 PATH / 整个复制到 exe 同级目录）。
- MVS 5.1 的安装布局参考：`MVCAM_COMMON_RUNENV = D:\Program Files\MVS\Development`，
  封装在 `DotNet\AnyCpu\netstandard2.0\`（**比老版本多一层 TFM 目录**，csproj 已兼容探测）。
- **位数必须一致**：MVS 封装 + 原生库同为 x64；本程序 AnyCPU 在 x64 系统跑 64 位，
  与雷赛 LTDMC.dll 位数也要一致，否则 `BadImageFormatException` → 降级 Virtual + AL201。

**接入步骤（二选一，编译时输出窗口会打印实际选用的 dll）**

1. **默认**：直接用仓库内的 `libs/MvCameraControl.Net.dll`，机器上装好 MVS（提供原生库）即可。
   编译时会打印：`海康 MVS: 使用 …\libs\MvCameraControl.Net.dll（HAS_MVS 已启用）`。
2. **换 SDK 版本**：把新版本的 `MvCameraControl.Net.dll` 覆盖到 `libs/`；或删除 `libs/` 下的
   dll，让工程自动探测 `%MVCAM_COMMON_RUNENV%\DotNet\AnyCpu\netstandard2.0\`。

未探测到 dll 时编译的是占位实现：`Initialize()` 返回 false → 降级 Virtual 相机 + 报 AL201，
工程仍可正常编译运行（03 文档第 7 节验收 1、2）。

**常见错误码**

| 错误码 | 含义 | 处理 |
|---|---|---|
| `0x80000203` | 设备被占用（MV_E_ACCESS_DENIED） | 关掉 MVS 客户端 / 其它取图程序，同一台相机只能被一个进程独占 |
| `0x80000007` | 无数据（超时，未触发或曝光过长） | 检查 TriggerSource / 曝光与触发间隔；单次超时不判掉线 |
| `0x80000201` | 不支持（节点/功能该机型没有） | 换用该机型支持的节点，代码里非关键节点已降级为 Warning |

### 2.2 初始化流程

> MVS 4.x 的 .NET 封装是**实例 API**：`new MyCamera()` 代表一台相机，方法均带 `_NET` 后缀。
> 只有枚举设备是静态方法。下面的写法与 `Hardware/Camera/HikvisionCamera.cs` 一一对应。

```csharp
using MvCamCtrl.NET;

var camera = new MyCamera();                       // 一个实例 = 一台相机

// 1. 枚举设备（GigE + USB）
var deviceList = new MyCamera.MV_CC_DEVICE_INFO_LIST();
int ret = MyCamera.MV_CC_EnumDevices_NET(MyCamera.MV_GIGE_DEVICE | MyCamera.MV_USB_DEVICE, ref deviceList);
if (ret != MyCamera.MV_OK || deviceList.nDeviceNum == 0)
    return false;                                  // 交给上层降级 Virtual + AL201，不抛异常

// 2. 取设备信息（pDeviceInfo 是 IntPtr 数组，必须自己 marshal 成结构体）
var info = Marshal.PtrToStructure<MyCamera.MV_CC_DEVICE_INFO>(deviceList.pDeviceInfo[0]);

// 3. 创建句柄 + 打开
ret = camera.MV_CC_CreateDevice_NET(ref info);
ret = camera.MV_CC_OpenDevice_NET(MyCamera.MV_ACCESS_Exclusive, 0);

// 4. GigE 必须设最优包长（否则 6MP 大图容易丢帧）
if (info.nTLayerType == MyCamera.MV_GIGE_DEVICE)
{
    var packetSize = camera.MV_CC_GetOptimalPacketSize_NET();
    if (packetSize > 0)
        camera.MV_CC_SetIntValue_NET("GevSCPSPacketSize", (uint)packetSize);
}

// 5. 像素格式 Mono8（黑白相机最省带宽，下游按一像素一字节处理）
camera.MV_CC_SetEnumValueByString_NET("PixelFormat", "Mono8");

// 6. 设置触发模式（软触发）
camera.MV_CC_SetEnumValue_NET("TriggerMode", 1);                        // 1 = On
camera.MV_CC_SetEnumValueByString_NET("TriggerSource", "Software");     // 用字符串，避免枚举值随固件变化
camera.MV_CC_SetEnumValue_NET("TriggerActivation", 0);

// 7. 关闭自动曝光/自动增益（工业定位必须固定参数）
camera.MV_CC_SetEnumValue_NET("ExposureAuto", 0);                       // 0 = Off
camera.MV_CC_SetEnumValue_NET("GainAuto", 0);
camera.MV_CC_SetFloatValue_NET("ExposureTime", 5000f);                  // 5ms
camera.MV_CC_SetFloatValue_NET("Gain", 0f);

// 8. 读缓冲区大小（Mono8 全幅 3072×2048 = 6 291 456）
var payload = new MyCamera.MVCC_INTVALUE();
camera.MV_CC_GetIntValue_NET("PayloadSize", ref payload);

// 9. 开始采集
camera.MV_CC_StartGrabbing_NET();
```

> **枚举值常量**：优先用 SDK 提供的 `MyCamera.MV_CAMERA_...` 常量，不要硬编码数字。
> 若常量名不确定，用字符串节点名 + `MV_CC_SetEnumValueByString_NET`。
> 曝光/增益范围不要写死：`MV_CC_GetFloatValue_NET("ExposureTime", ref param)` 拿 `fMin/fMax` 再 `Math.Clamp`。

### 2.3 取一帧（同步阻塞方式，推荐用于本项目）

```csharp
// 触发
camera.MV_CC_SetCommandValue_NET("TriggerSoftware");

// 等待并取帧（缓冲区按 PayloadSize 分配，不要写死 width*height）
var frameInfo = new MyCamera.MV_FRAME_OUT_INFO_EX();
var buffer = new byte[payloadSize];                       // Mono8 一个像素一字节
var pinned = GCHandle.Alloc(buffer, GCHandleType.Pinned);
try
{
    int ret = camera.MV_CC_GetOneFrameTimeout_NET(
        pinned.AddrOfPinnedObject(), (uint)buffer.Length, ref frameInfo, timeoutMs);

    if (ret != MyCamera.MV_OK)
        return new CaptureResult { Success = false, ErrorMessage = $"取图失败 0x{ret:X8}" };

    // 像素格式必须校验：如果相机没切到 Mono8，nFrameLen 会大于 width*height，直接按灰度用会花屏
    if ((uint)frameInfo.enPixelType != 0x01080001)        // PixelType_Gvsp_Mono8
        return new CaptureResult { Success = false, ErrorMessage = "像素格式非 Mono8" };

    return new CaptureResult
    {
        Success = true,
        Mono8Data = buffer,
        Width = frameInfo.nWidth,
        Height = frameInfo.nHeight,
        Timestamp = DateTime.Now
    };
}
finally
{
    pinned.Free();
}
```

**注意**：
- 必须 `GCHandle.Alloc(..., GCHandleType.Pinned)` 固定托管数组再取地址，`fixed` 也行但跨方法传递不方便
- 缓冲区大小要按**实际帧的 payload 大小**分配（`MV_CC_GetIntValue_NET("PayloadSize")`），不要固定写死
- 单次超时**不等于**掉线：累计 5s 无有效图才报 AL201（本文件第 6 节），否则一次没来料就报警

### 2.4 释放（必须按顺序）

```csharp
if (_grabbing) camera.MV_CC_StopGrabbing_NET();
camera.MV_CC_CloseDevice_NET();
camera.MV_CC_DestroyDevice_NET();
```

**掉线检测**：GigE 相机网线拔掉后，`GetOneFrameTimeout` 会超时。捕获超时 → 触发 `Fault` 事件 → 上层报警 → 后台每 3s 尝试重新 `OpenDevice`。

## 3. Mono8 → OpenCV Mat 转换（关键实现）

```csharp
namespace AutoTaping.Vision;

public static class ImageConverter
{
    /// <summary>Mono8 原始数据 → 灰度 Mat（不拷贝，需保证 data 生命周期）</summary>
    public static Mat ToMat(byte[] mono8, int width, int height)
    {
        var mat = new Mat(height, width, MatType.CV_8UC1);
        Marshal.Copy(mono8, 0, mat.Data, width * height);
        return mat;
    }

    /// <summary>Mat → BitmapSource（用于 WPF 显示）</summary>
    public static BitmapSource ToBitmapSource(Mat mat)
    {
        if (mat.Empty()) return BitmapSource.Create(1, 1, 96, 96,
            PixelFormats.Gray8, null, new byte[1], 1);

        // 统一转灰度 8 位
        Mat gray = mat;
        if (mat.Channels() != 1)
        {
            gray = new Mat();
            Cv2.CvtColor(mat, gray, ColorConversionCodes.BGR2GRAY);
        }

        int stride = (int)gray.Step();
        BitmapSource bs = BitmapSource.Create(
            gray.Width, gray.Height, 96, 96,
            PixelFormats.Gray8, null, gray.Data, stride * gray.Height, stride);

        bs.Freeze();   // ★ 必须 Freeze，否则跨线程使用会抛异常
        if (!ReferenceEquals(gray, mat)) gray.Dispose();
        return bs;
    }
}
```

**性能要求**：1280×1024 灰度图，转换 + Freeze < 10ms。

## 4. VirtualCamera（模拟实现，必须实现）

### 4.1 行为要求

| 行为 | 规则 |
|---|---|
| 图片来源 | `Hardware:Camera:SampleImageDirectory` 指定目录（默认 `images/samples`）内的 `*.png/*.bmp/*.jpg`，每次取图**随机取一张**（自动转灰度） |
| 样本图从哪来 | `tools/SampleGen` 生成（随机 ΔX/ΔY/Δθ 的模拟相机画面），构建时复制到输出目录 `images/samples` |
| 无图片时 | 生成带 MARK 的合成图（噪声底 + 大小两个实心圆：r=15 在 (400,500)、r=9 在 (880,500)） |
| 姿态差异 | 不再注入偏移：样本图自带不同姿态，每次拍照的纠偏量天然不同 |
| 平台位置模拟 | 九点标定期间调用 `SetPlatformPosition`，此时**强制走合成图**（像素与平台位置必须确定性对应），标定结束后 `ClearPlatformPosition` 恢复样本图 |
| 触发延迟 | 模拟 80–150ms 取图耗时 |
| 掉线模拟 | 支持"手动断开"按钮，用于演示报警 |

## 5. 相机参数配置表

| 参数 | 节点名 | 典型值 | 说明 |
|---|---|---|---|
| 曝光 | `ExposureTime` | 3000–8000 μs | 车间 LED 照明下 5ms 左右 |
| 增益 | `Gain` | 0–5 dB | 尽量用 0，增益会放大噪声 |
| 触发模式 | `TriggerMode` | On | 定位应用必须用触发 |
| 触发源 | `TriggerSource` | Software | 上位机控制时机 |
| 像素格式 | `PixelFormat` | Mono8 | 黑白相机最快最省带宽 |
| 帧率使能 | `AcquisitionFrameRateEnable` | false | 触发模式下不需要限帧 |
| 自动曝光 | `ExposureAuto` | Off | **必须关闭**，否则每帧亮度不一致，模板匹配会飘 |

**重要**：自动曝光/自动增益必须关闭。这是新手最常犯的错，也是现场"标定好了但第二天又不准"的主要原因。

## 6. 通信与掉线处理

```
采集线程每 200ms 检查相机状态（通过 ICamera.IsConnected + 最近成功取图时间）
   ↓ 超过 5s 无成功取图
触发 CameraFault 事件
   ↓
AlarmService 报 AL201「相机通讯中断」
   ↓
自动流程：暂停（不是继续乱跑）
   ↓
后台每 3s 尝试重新初始化
   ↓ 成功
清除报警，提示「相机已恢复」，流程保持暂停等待人工确认
```

**不允许**：相机掉线后自动继续跑（可能贴到空位造成撞机）。

## 8. 本文件的约束

1. 所有 SDK 调用只能出现在 `Hardware/Camera/HikvisionCamera.cs`
2. 相机对象**不可多线程并发取图**，必须加锁
3. 取图必须在后台线程，不得在 UI 线程调用
4. `BitmapSource` 必须 `Freeze()` 后才能跨线程
5. 必须实现 Virtual 版本，且能注入偏移模拟
6. 自动曝光必须强制关闭，代码里写死而不是靠配置
