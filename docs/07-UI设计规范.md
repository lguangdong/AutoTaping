# 07 - UI 设计规范

> **设计基准分辨率：1280 × 1024（4:3，工控触摸屏最常见）**
> 必须保证在该分辨率下完整显示，1920×1080 下等比放大不破版。

---

## 1. 设计原则（工控场景专属）

| 原则 | 说明 |
|---|---|
| **大字大按钮** | 操作工戴手套、站在 0.5m 外，最小可点区域 88×56 px |
| **高对比** | 车间强光，不用浅灰字、不用细线、不用半透明 |
| **颜色即状态** | 绿=正常、黄=警告、红=故障，不允许装饰性用色 |
| **单手可达** | 关键操作（启动/停止/急停状态）固定在右下或底部 |
| **永不遮挡** | 状态栏和操作条永远可见，弹窗不得覆盖操作条 |
| **无动画** | 不做淡入淡出、不做旋转 Loading（干扰判断） |

## 2. 色板（Resources/Colors.xaml）

### 2.1 背景与面板

| 名称 | 色值 | 用途 |
|---|---|---|
| `BgMain` | `#1E1E1E` | 主背景（深灰，减少眩光） |
| `BgPanel` | `#2D2D30` | 面板背景 |
| `BgCard` | `#3A3A3D` | 卡片/分组框 |
| `BgInput` | `#252526` | 输入框背景 |
| `BorderNormal` | `#4A4A4D` | 边框 |

### 2.2 文字

| 名称 | 色值 | 用途 |
|---|---|---|
| `TextPrimary` | `#FFFFFF` | 主文字、数值 |
| `TextSecondary` | `#B8B8B8` | 说明文字、单位 |
| `TextDisabled` | `#6B6B6B` | 禁用态 |
| `TextLink` | `#4FC3F7` | 可点击文字 |

### 2.3 状态色（**语义固定，不得他用**）

| 名称 | 色值 | 语义 | 用在哪 |
|---|---|---|---|
| `StatusRun` | `#4CAF50` | 运行中 / 正常 / OK | 状态灯、工位、三色灯绿 |
| `StatusIdle` | `#9E9E9E` | 空闲 / 停止 / 离线 | 未连接设备、空闲工位 |
| `StatusWait` | `#FFC107` | 等待 / 提示 | 等待料、提示级报警 |
| `StatusWarn` | `#FF9800` | 警告 | 警告级报警、参数接近超限 |
| `StatusAlarm` | `#F44336` | 故障 / 严重 | 严重报警、急停、红灯 |
| `StatusInfo` | `#2196F3` | 信息 / 选中 | 导航选中态 |

### 2.4 按钮

| 名称 | 色值 | 用途 |
|---|---|---|
| `BtnPrimary` | `#1976D2` | 主操作（启动） |
| `BtnPrimaryHover` | `#2196F3` | 悬停 |
| `BtnDanger` | `#C62828` | 危险操作（停止、急停复位） |
| `BtnNormal` | `#424242` | 普通操作 |
| `BtnDisabled` | `#2A2A2A` | 禁用（文字用 `TextDisabled`） |

> **深色主题说明**：工控现场强光环境下，深色背景 + 高亮文字比浅色更耐看，且不易留指纹。若客户要求浅色，只改 `Colors.xaml`，不改任何 View。

## 3. 字号与字体

| 用途 | 字体 | 字号 | 粗细 |
|---|---|---|---|
| 页面标题 | Microsoft YaHei | 28 | Bold |
| 分组标题 | Microsoft YaHei | 22 | Bold |
| 正文 | Microsoft YaHei | 20 | Normal |
| **关键数值** | **Consolas** | **28** | **Bold** |
| 单位 | Microsoft YaHei | 18 | Normal |
| 表格内容 | Microsoft YaHei | 20 | Normal |
| 辅助说明 | Microsoft YaHei | 16 | Normal |

**为什么关键数值用 Consolas**：等宽字体让数字不跳动（实时刷新时 1 和 8 宽度相同），避免视觉抖动。这是工控界面的细节。

**最小字号 16**，不允许更小。

## 5. 布局结构

### 5.1 主窗口（MainWindow）

```
┌──────────────────────────────────────────────────────────────┐
│ ① 状态栏  Height=64                                           │
│  [●运行中] 配方:A123-3M  产量:1024/2000  良率:99.2%  ⚠3  👤tech01 │
│                                                    2026-11-05 10:23:45 │
├────────┬─────────────────────────────────────────────────────┤
│ ②      │                                                      │
│ 导航   │  ③ 内容区 ContentControl                             │
│ Width  │     放置各 Page，动态切换                             │
│ =120   │                                                      │
│        │                                                      │
├────────┴─────────────────────────────────────────────────────┤
│ ④ 操作条  Height=96                                           │
│ [ 启 动 ] [ 暂 停 ] [ 停 止 ] [ 复 位 ]   节拍 3.2s  ● 急停:正常 │
└──────────────────────────────────────────────────────────────┘
```

| 区域 | 高度/宽度 | 内容 |
|---|---|---|
| ① 状态栏 | 64 | 状态灯、配方名、产量、良率、未确认报警数、当前用户、时间 |
| ② 导航栏 | 宽 120 | 8 个图标+文字按钮，垂直排列 |
| ③ 内容区 | 剩余 | 各页面 |
| ④ 操作条 | 96 | 启动/暂停/停止/复位 + 节拍 + 急停状态 |

**状态栏元素从左到右**：
1. 状态指示灯（圆点 + 文字，颜色随状态变）
2. 当前配方名
3. 产量（已产/目标）
4. 良率
5. 未确认报警数（红底白字，点击跳转报警页）
6. 当前用户 + 角色
7. 系统时间（每秒刷新）

### 5.2 导航栏

| 图标 | 文字 | 页面 | 权限 |
|---|---|---|---|
| ▶ | 自动运行 | AutoPage | 全部 |
| ✥ | 手动调试 | ManualPage | 技术员+ |
| ☰ | 参数配方 | RecipePage | 操作员可看，技术员可改 |
| ◎ | 视觉标定 | VisionPage | 技术员+ |
| ⚠ | 报 警 | AlarmPage | 全部 |
| ▤ | 产量统计 | OutputPage | 全部 |
| ⊞ | IO 监控 | IoPage | 技术员+ |
| ⚙ | 系统设置 | SystemPage | 工程师 |

**权限不足时**：导航按钮**置灰但仍显示**（不要隐藏，否则用户不知道为什么找不到）。

```

```

| 状态 | 颜色 | 判定 |
|---|---|---|
| 正常 | `StatusRun` | 最近 3s 内有成功通讯 |

## 8. 弹窗规范

| 类型 | 用途 | 要求 |
|---|---|---|
| **确认弹窗** | 危险操作二次确认 | 必须显示"操作内容 + 影响"，默认按钮为「取消」 |
| **输入弹窗** | 数值输入（如目标位置） | 带单位、带范围提示、非法输入即时红框 |
| **错误弹窗** | 操作被拒绝 | 说明原因 + 建议做法，**不要只说"操作失败"** |
| **登录弹窗** | 身份切换 | 密码框支持回车提交 |

### 确认弹窗模板

```
┌────────────────────────────────┐
│  ⚠ 确认操作                     │
│                                │
│  即将【复位报警】并清除当前进度。 │
│  设备将停止运行。                │
│                                │
│      [ 取 消 ]   [ 确 认 ]      │
└────────────────────────────────┘
```

**默认焦点必须在「取消」上**，防止误触回车。

## 9. WPF 实现要求

### 9.1 样式集中管理

```
Resources/
├── Colors.xaml     # 所有 Color / SolidColorBrush
├── Fonts.xaml      # 字号常量
├── Styles.xaml     # Button / TextBox / DataGrid / GroupBox 样式
└── Icons.xaml      # 矢量图标（Path Data）
```

`App.xaml` 中按顺序合并。**禁止在 View 里写死颜色和字号**。

### 9.2 按钮样式示例

```xml
<Style x:Key="PrimaryButton" TargetType="Button">
    <Setter Property="MinWidth" Value="160"/>
    <Setter Property="MinHeight" Value="72"/>
    <Setter Property="FontSize" Value="24"/>
    <Setter Property="FontWeight" Value="Bold"/>
    <Setter Property="Foreground" Value="White"/>
    <Setter Property="Background" Value="{StaticResource BtnPrimary}"/>
    <Setter Property="BorderThickness" Value="0"/>
    <Setter Property="Template">
        <Setter.Value>
            <ControlTemplate TargetType="Button">
                <Border Background="{TemplateBinding Background}"
                        CornerRadius="4">
                    <ContentPresenter HorizontalAlignment="Center"
                                      VerticalAlignment="Center"/>
                </Border>
                <ControlTemplate.Triggers>
                    <Trigger Property="IsMouseOver" Value="True">
                        <Setter Property="Background" Value="{StaticResource BtnPrimaryHover}"/>
                    </Trigger>
                    <Trigger Property="IsEnabled" Value="False">
                        <Setter Property="Background" Value="{StaticResource BtnDisabled}"/>
                        <Setter Property="Foreground" Value="{StaticResource TextDisabled}"/>
                    </Trigger>
                </ControlTemplate.Triggers>
            </ControlTemplate>
        </Setter.Value>
    </Setter>
</Style>
```

### 9.3 禁用态必须可见

禁用按钮不能只是"点了没反应"，必须**视觉上明显变灰**。工控现场最常见的投诉是"这个按钮按了没反应"（其实是不满足条件）。

## 10. 禁止事项

| ❌ 禁止 | 原因 |
|---|---|
| 使用浅灰文字（`#666` 以下）配深色背景 | 车间看不清 |
| 使用半透明遮罩 | 强光下看不见 |
| 用颜色做非状态用途（如蓝色标题装饰） | 状态色必须语义唯一 |
| 弹窗遮住底部操作条 | 故障时够不到停止 |
| 用 Tooltip 承载关键信息 | 触摸屏没有悬停 |
| 下拉菜单层级 > 2 | 戴手套点不准 |
| 自动跳转页面 | 操作工正在看时被切走 |
| 使用动画/过渡 | 干扰判断，且老工控机卡 |

---

## 11. 本文件的约束

1. 所有颜色、字号、尺寸必须引用资源字典，不得硬编码
2. 1280×1024 下不得出现滚动条（页面必须适配）
3. 状态色只用于状态，不得用作装饰
4. 所有禁用控件必须有明显视觉差异
5. 弹窗不得覆盖底部操作条
